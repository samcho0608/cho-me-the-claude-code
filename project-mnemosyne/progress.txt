### Learnings
- Mixed TS/Python stack: IPC via JSON stdout, one JSON object per invocation
- Python subprocesses are stateless — temp dir per invocation
- Exit codes: 0=success, 1=analysis error, 2=invalid input, 3=render unavailable
- Config precedence: CLI flags > env vars > config/mnemosyne.json > hardcoded defaults
- L_vis fast mode uses edge density (E/N) not Euler surplus (better for planar graphs)
- analysis_mode recorded in report; cross-mode refactor guard rejects mismatched pairs

### Patterns discovered
- All Python modules accept --input/--output file paths and write JSON to output path
- spatial_mapper.ts runs in-process (no subprocess) — avoids JSON serialization of large DOM data
- Temp dir cleaned up at end of analyze.ts orchestration (finally block)
